## 实测发现与限制

- **搜狗 BIN 存在样本兼容差异。** `sougoubak.bin`（1,054 字节）在浏览器中被拒绝；原生 CLI 同样拒绝，不能将该格式声明为全面兼容。另一个 `搜狗备份.bin` 真实文件成功导入 30 条，并通过线上 Firefox 复核。
- **百度手机英文仅适用于 ASCII 英文。** 中文样本经该导出器写为问号，不能保留中文。改用 hello/world/cloudflare 的英文样例后导出、导入往返通过。这是格式编码限制，不能将英文测试通过视为支持中文。
- Emoji 与 Rime UserDb 本轮使用按解析格式构造的最小文本样本，不属于独立用户词库文件；Rime UserDb 的验证只覆盖文本条目，不代表原始数据库容器可直接读取。
- 已知 Big5 输入解码、Gboard ZIP 输入及 Rime 缺少 YAML 文件头的限制仍保留，未通过本次验收消除。
- 本轮未执行 Safari/iOS 真机完整验收；历史 Safari 示例验证不能替代本轮覆盖。
- 大文件验证覆盖超 50 MiB 时拒绝导入，以及 25 万词条任务可取消；不代表 50 MiB 文件能在所有手机上完成。

## 证据与复现

原始 JSON、下载文件、ZIP、截图位于 `artifacts/verification/online/`。`format-matrix-initial.json` 保留首次有 2 个失败样例和 2 个未覆盖入口的结果；`followup-firefox.json` 记录复核，最终结果见 `format-matrix.json`。本次没有修改或重新发布生产应用。

`node scripts/test-browser.mjs --online` 执行线上功能及格式检查。它注入测试客户端连接线上原版 Worker，不在网站部署测试入口。界面路径仍使用实际线上页面与下载文件。Firefox 复现需 Geckodriver，使用 `TEST_URL`、`REPORT_DIR` 和 `EXTENDED_UI=1` 运行 `tests/firefox.py`。
