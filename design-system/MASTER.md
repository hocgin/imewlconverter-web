# 词库转转 · Neubrutalism

本文件为此网站的视觉约定，优先于仓库中 HeroUI 默认主题的通用方向。

## 色彩与构图

- 奶油白画布 `#f7f5ee`，纸白表面 `#fffefa`，墨黑文字与边界 `#20201e`。
- 亮黄主操作 `#ffdf49`，电蓝强调 `#2955d9`；粉色仅作为少量辅助装饰。
- 主面板 2.5–3px 黑边、4–6px 实色偏移阴影；控件 1.5–2px 黑边、约 4px 圆角。
- 无渐变、模糊和远程图片；插图用 SVG 图标与 CSS 词库卡片构成。
- 标题粗体，正文使用本地系统中文字体。数字与扩展名使用等宽字体。

## 工作区与适配

- 首屏为转换工作台，桌面文件/设置双栏，移动端单栏。
- 768px 以下显示底部固定操作栏，预留底部内容空间并使用安全区 inset。
- 主要内容最大宽度 1184px；桌面侧边距 24px，手机 20px。
- 高级设置、格式目录与帮助按需展开，主转换路径保持可见。
- 所有交互提供键盘焦点，按钮和单独操作目标至少 44px，状态使用文字和颜色共同表达。
- 轻量按压仅改变 transform 和阴影，约 120ms；遵守 `prefers-reduced-motion`。

## 组件

使用 HeroUI v3 复合组件及 React Aria 行为，不添加 v2 Provider。Tailwind v4 必须先于 HeroUI CSS 导入。颜色、表面、边框及阴影通过全局语义变量统一配置。

Neubrutalism 方向经 ui-ux-pro-max 的明确 `style` 查询确认；通用设计系统查询曾误匹配 Neumorphism，没有采用该结果。
